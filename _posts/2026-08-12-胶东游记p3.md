## 威海  ——赶海真好玩😋  

### 赶海的两天  

离开青岛，搭上去威海的无座高铁，车程大约2小时。一路上阳光明媚。透过车门处的玻璃，云朵和电线杆交错闪过，耳机里放着愉悦的小曲，心情也跟着轻快起来。

![窗外风景](/assets/images/2026-08-12_jiaodong_travel_p3/2026-08-12_jiaodong_travel_p3_img1.webp){:width="75%" loading="lazy" style="display: block; margin: 0 auto;"}

威海以热情的天气迎接我们，小站台容不下这么多人一次性下车，所有人都挤在站台上。不过说实话这种小车站的开放式站台比大车站的封闭式站台更有趣，能看到更多的风景。可以欣赏到铁路和周围环境的互动。

![威海站站台1](/assets/images/2026-08-12_jiaodong_travel_p3/2026-08-12_jiaodong_travel_p3_img2.webp){:width="75%" loading="lazy" style="display: block; margin: 0 auto;"}

![威海站站台2](/assets/images/2026-08-12_jiaodong_travel_p3/2026-08-12_jiaodong_travel_p3_img3.webp){:width="75%" loading="lazy" style="display: block; margin: 0 auto;"}

在酒店稍微休整一下，去海边玩。威海的海边有很多适合赶海的地方，退潮的时候，可以看到很多小螃蟹、贝壳和海藻。  

我们去的地方就是酒店附近的九龙湾公园，既有沙滩又有礁石，适合赶海。我们带上小桶和小铲子，开始了我们的赶海之旅。  

人很多，我们捡的净是些不会跑的小贝壳。看得到水坑里面有灵活的小鱼，但很可惜我们的笨手抓不住。小螃蟹也很机灵，看到我们靠近就迅速钻进沙子里。

幸运地找到了海星。

![海星](/assets/images/2026-08-12_jiaodong_travel_p3/2026-08-12_jiaodong_travel_p3_img4.webp){:width="75%" loading="lazy" style="display: block; margin: 0 auto;"}

眼尖的我发现了寄居蟹。

![寄居蟹](/assets/images/2026-08-12_jiaodong_travel_p3/2026-08-12_jiaodong_travel_p3_img5.webp){:width="75%" loading="lazy" style="display: block; margin: 0 auto;"}

甚至有海葵。

![海葵](/assets/images/2026-08-12_jiaodong_travel_p3/2026-08-12_jiaodong_travel_p3_img6.webp){:width="75%" loading="lazy" style="display: block; margin: 0 auto;"}

海边的日落也令人陶醉，夕阳的余晖洒在海面上，波光粼粼，像金沙撒在了水里。正如古文里所写的：“浮光跃金，静影沉璧。”  

![浮光跃金](/assets/images/2026-08-12_jiaodong_travel_p3/2026-08-12_jiaodong_travel_p3_img7.webp){:width="75%" loading="lazy" style="display: block; margin: 0 auto;"}

热烈的云彩下是自由的海鸥。

![海鸥](/assets/images/2026-08-12_jiaodong_travel_p3/2026-08-12_jiaodong_travel_p3_img10.webp){:width="75%" loading="lazy" style="display: block; margin: 0 auto;"}

在沙滩上走走停停，蹲着捡拾贝壳，不知不觉就到了夜晚。夜晚的海边有着不同的风情，海风吹拂着脸庞，带来阵阵凉意。我们在沙滩上点起了小灯，听着海浪拍打礁石的声音，感受着大自然的宁静与美好。  

![挑灯的人](/assets/images/2026-08-12_jiaodong_travel_p3/2026-08-12_jiaodong_travel_p3_img11.webp){:width="75%" loading="lazy" style="display: block; margin: 0 auto;"}

黄昏之时，会看着岸边，云彩和灯光如此鲜艳而静谧。

![黄昏1](/assets/images/2026-08-12_jiaodong_travel_p3/2026-08-12_jiaodong_travel_p3_img12.webp){:width="75%" loading="lazy" style="display: block; margin: 0 auto;"}

![黄昏2](/assets/images/2026-08-12_jiaodong_travel_p3/2026-08-12_jiaodong_travel_p3_img13.webp){:width="75%" loading="lazy" style="display: block; margin: 0 auto;"}

远处的港口仍然灯火通明，也许是工人们还在忙碌着，准备着船只的出航。夜色下的港口，灯光映照在水面上，随着海浪起伏，像跳动的烛火。

![港口](/assets/images/2026-08-12_jiaodong_travel_p3/2026-08-12_jiaodong_travel_p3_img14.webp){:width="75%" loading="lazy" style="display: block; margin: 0 auto;"}

### 烤肉香的得嘞  

威海的一大特色就是韩国料理，由于地理位置的原因，威海有很多韩国人居住和经商，所以韩国料理在这里非常受欢迎。我们选择了一家评价不错的韩国烤肉店，点了牛肉、五花肉和一些蔬菜。

### 写在威海之后

威海的行程我们就去海边赶了两天海，其他哪也没去，也挺好。本来计划的是去布鲁威斯号沉船。后来感觉这个地方太远了，交通不便，而且只有这一个看点。想想那些照片，自己去也是拍出来一样的东西，其他的人把这艘船的左右，早中晚，春夏秋冬，有海鸥和没海鸥的时候都拍了个遍。我去拍也不过就是重复而已。也许发到朋友圈有人会点赞，不过那样又怎样呢。只能说我拍了一张好看的照片，不能说是一张好照片~~也许其实好看也算不上~~。  

晚上思考了很久，好照片是什么。我觉得好的照片是有内容、有想法的照片。传递的不应该只是画面，也不是所谓氛围感，更不止于某种情绪。好的照片里面应当有作者的思考，也能引起观者的思考。我不能说我拍的是好照片，也不能说我拍的是好看的照片。我尝试着通过照片去表达我的思考，也许当下还不够成熟，不过多拍总是好的。继续拍下去，继续思考，继续成长。  

那天晚上我和Elma吃完晚饭~~山东外卖饭量真大，80块2荤2素四碗饭，关键是炒的还很好~~，在酒店聊天聊到凌晨三点。电视里面放着演唱会的MV。我们聊了很多，聊了很多关于生活，关于摄影，关于旅行，关于人生的事情。我们改变了很多，也都成长了很多。这里放两首我们都喜欢的歌，献给青春和未来。
