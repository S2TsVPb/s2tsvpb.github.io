## 青岛  ——质感独特的海边小城  

### 青岛的第二天

两个懒人依旧是睡觉睡到10点多，决定早饭吃两个小饼干，出门直接走去吃午饭。找了个海鲜小馆，大众点评上评分还不错。  

#### 海鲜夯爆了1

原来我对海产品没什么兴趣的，因为家里烧的海鲜要么是没味道，要么是腥味很重，我从来没在南京吃出过让我觉得“鲜”的味道。这次在真正的沿海城市吃美了。  

![海鲜大餐1](/assets/images/2026-08-09_jiaodong_travel_p2_img1.jpg){:width="75%" style="display: block; margin: 0 auto;"}

一个海鲜套餐加上两瓶啤酒，人均65元。可以说性价比很好了。新鲜的海鲜不需要过多的调味，清蒸或水煮一下，撒上葱花，浇上热油和淡口酱油味道就是绝佳。海鲜的鲜味和啤酒的醇厚相互衬托，真是绝配。另外还尝试了特色鲅鱼水饺，里面是鲅鱼加韭菜，味道也很鲜美。

#### 常在海边走，哪有不湿鞋

下午下着小雨，我们坐地铁向着八大关前进。细细的小雨中，八大关的景色别有一番风味。雨水打在树叶上，发出沙沙的声音，空气中弥漫着海水的咸味和泥土的清新。我们撑着伞，沿着石板路慢慢走着，欣赏着各式各样的欧式建筑。  

由于是阴天，这部分的调色有些激进，饱和度拉低。

![八大关近看](/assets/images/2026-08-09_jiaodong_travel_p2_img2.jpg){:width="75%" style="display: block; margin: 0 auto;"}

![海面](/assets/images/2026-08-09_jiaodong_travel_p2_img3.jpg){:width="75%" style="display: block; margin: 0 auto;"}

![八大关远看](/assets/images/2026-08-09_jiaodong_travel_p2_img4.jpg){:width="75%" style="display: block; margin: 0 auto;"}

八大关的附近就是一个海水浴场，天气飘着小雨，不过海边任然有玩沙戏水的人。从岸边有一条防波堤伸向海里，我们走到防波堤的尽头，向后回望海岸线。  

![雾中的高楼](/assets/images/2026-08-09_jiaodong_travel_p2_img5.jpg){:width="75%" style="display: block; margin: 0 auto;"}

拍这张照片的时候我们就已经站在海岸边的礁石上了，当时是下午3点多，正是涨潮的时候，而我们对此浑然不知。

![站在礁石上的Elam](/assets/images/2026-08-09_jiaodong_travel_p2_img6.jpg){:width="75%" style="display: block; margin: 0 auto;"}

图为Elam站在礁石上，此时已经开始涨潮了。海水逐渐封住了礁石的缝隙，海水慢慢地向我们逼近。我们决定回到岸边，没想到回去的路上，海水已经漫过了石滩，一条小路也没能留下。好巧不巧我们穿的全是运动鞋，海水漫过鞋子，鞋子湿透了。只好挽起裤腿返回岸边。

鞋湿了，下午的其他形成泡水了，我们决定回酒店换衣服。去地铁站的路上，雨越下越大，我伸手掏包侧面的伞，没找到，可能是掉在什么地方了。于是两人挤在一把小伞下，一边淋着雨一边赶到了地铁站。

![雨中青岛1](/assets/images/2026-08-09_jiaodong_travel_p2_img7.jpg){:width="75%" style="display: block; margin: 0 auto;"}

![雨中青岛2](/assets/images/2026-08-09_jiaodong_travel_p2_img8.jpg){:width="75%" style="display: block; margin: 0 auto;"}

这个教堂加上这个半死不活的天气，像到了东欧。  

#### 海鲜夯爆了2

我们到台东夜市觅食，找了个评分不错的海鲜烧烤店。台东夜市大部分都是摆摊的小车，属于复制黏贴的夜市，看多了会有些审美疲劳。但是晚餐依旧是不错的，点名表扬海肠捞饭，海肠的鲜亮弹牙，配上米饭和酱汁，味道很给到满分。另外还点了笔管鱼，辣炒蛏子和和烤生蚝。笔管鱼的口感很像鱿鱼，蛏子和生蚝都很新鲜。我们还点了两瓶啤酒。  

![海鲜大餐2](/assets/images/2026-08-09_jiaodong_travel_p2_img9.jpg){:width="75%" style="display: block; margin: 0 auto;"}

吃饱喝足，走回酒店的路上，雨已经停了。夜晚的青岛街道上，灯光映照在湿漉漉的地面上，反射出五彩斑斓的光影。我们沿着无人街道慢慢走着。从路边的水洼，明白了什么是“就算大雨让这座城市颠倒”。  

![水洼里的另一个世界](/assets/images/2026-08-09_jiaodong_travel_p2_img10.jpg){:width="75%" style="display: block; margin: 0 auto;"}

### 青岛的第三天

#### 海鲜面也很好吃

依旧公式化睡懒觉，两人睡到11点多才起床。早餐直接skip，慢走去吃海鲜面。面条劲道，汤头鲜美，配上丰富的海鲜料，好看又好吃😋。  

![海鲜面](/assets/images/2026-08-09_jiaodong_travel_p2_img11.jpg){:width="75%" style="display: block; margin: 0 auto;"}

#### 再见青岛

我们又在市南区闲逛了一会，退房后坐高铁去威海。退房那天恰好是酒店的周年庆，酒店送了我们一份小蛋糕，吃着心里美滋滋。  

![街边告示栏](/assets/images/2026-08-09_jiaodong_travel_p2_img12.jpg){:width="75%" style="display: block; margin: 0 auto;"}
