## 出发之前  

这次的行程基本是两个人的临时起意。7月14号那天晚上我和朋友Elma聊天，以下简称朋友为E。两人都有出游的打算。我聊天框里的“我想去青岛”还没打出来，他就说他也想去青岛。就是这么心有灵犀。那天晚上我们就开始研究，怎么去，去那些地方，多长时间。我们还提前看了天气预报，想找几个晴天。研究这些东西也不容易，光是出发时间就想了好久，看着12306上面去青岛北站的二等座由有票变到16张，再变成10张——我知道我们不能再等了。于是7月16号一早上出发去青岛，21号下午从烟台返回。  

即将出发做打算的时候是最兴奋的，出游的喜悦就这样明晃晃地摆在眼前触手可及。玩过之后回想起来发现行程其实有点匆忙，如果少去一些地方，比如只去一个或者两个城市，可能会更好一些。  

当然准备的拍摄设备是不能少的。我带上了我的Z7II和24-70 f/4镜头，还有用来拍视频的pocket 3。Elma带上了他的祖传D90。准备好好记录一下。  

![准备的拍摄设备](/assets/images/2026-08-09_jiaodong_travel_p1_img1.jpg){:width="75%" style="display: block; margin: 0 auto;"}

胶片机出于轻量化的考虑没有带上。还有一个原因是我身边的胶卷给我过了两次安检机，我怕胶卷已经受损拍出来奇奇怪怪的鬼影，所以就没有带上。

## 青岛  ——质感独特的海边小城  

### 青岛的第一天

4个小时的高铁丝毫不能削减我们出游的热情，一路上也没少规划行程。AI规划了不少，不过最后还是想去哪去哪。规划行程真的不能看太多社交媒体，很多推荐的地方其实都是过度包装的景观化打卡点。路上刷了会小红书，感觉小红书是一个情绪化的平台，很多夸张的表述 *“避雷！千万不要来！”*， *“此生必去！！”*。有些 *“千万别来！”*仅仅是因为当天天气不好不能出片。看多了情绪化的表述之后，会让人对一个地方产生偏见；看多了不同人相互矛盾的表述之后，会让人对一个地方产生怀疑。我们还是按自己的节奏来，亲身体会感受，无论天气如何，有人的地方都会有阴晴雨雪，也肯定有喜怒哀乐。  

#### 让人惊喜的民宿

高铁一路上经过的地方天气都不算晴朗，青岛的天气也不例外。我们到达青岛北站的时候已经是下午1点多，天气阴沉沉的。先去酒店入住，然后步行去栈桥。我们住的地方在观象山附近，叫“想住Re-stay酒店”。酒店刚装好一年，设施都很新。五层的小楼，既有单间又有青旅房间，我们入住那时恰逢开业一周年庆，迟到了免费的蛋糕。室内不算宽敞，但好在布置温馨合理，干净整洁。房间在五楼，带一个小阳台。凭栏远眺，一侧是老城的黄墙红瓦，另一侧是现代化的玻璃幕墙，历史与现代在此交织碰撞，构成了独特的风景。

#### 老城区里的街溜子

就这样漫步在青岛的老城，走着走着天就慢慢放晴了。走过老宅子，走过立交桥，走过圣弥厄尔主教堂，走到栈桥。栈桥伸入湛蓝色的大海，尽头是一个小小的亭子，叫做“回澜阁”。栈桥上一路上各色行人，小商小贩，旅拍导游。之前对国内旅游的印象就是人多，但是后来慢慢接受了这种热闹，接受了这种人来人往的景象。

从栈桥上走下来，看见网红啤酒交易所，打了一斤原浆。来青岛了当然要喝青岛啤酒，和其他地方喝的啤酒确实不一样，麦香浓郁，喝完后感觉脚底生风，走路轻飘飘。

继续在老城区闲逛，一路上阳光正好，明亮却不刺眼。阳光照在浅黄色的老房子上，照在红色的屋顶上，照在青色的窗户上，鲜艳但不艳俗，有着玉石一样的温润。青岛的街头很干净，几乎可以说是一尘不染。老城区的建设也很收敛，新建的建筑也很好的融入了老城区的风格，不会让人感到突兀或是违和。  

![德式建筑](/assets/images/2026-08-09_jiaodong_travel_p1_img10.jpg){:width="75%" style="display: block; margin: 0 auto;"}

![老城区的房屋](/assets/images/2026-08-09_jiaodong_travel_p1_img11.jpg){:width="75%" style="display: block; margin: 0 auto;"}

经过一个街角，道路向海面延伸，电线错落有致的排布再路两旁。远处的船只好像停着不动，海面上有几只海鸥在盘旋。我们走在这条小路上，海风吹过来，带着咸味和湿润的气息。下图为Elma坐在路边，望着远方的海面发呆。  

![伸入海边的小路](/assets/images/2026-08-09_jiaodong_travel_p1_img12.jpg){:width="75%" style="display: block; margin: 0 auto;"}

#### 信号山公园

我们就这样走到了信号山公园，可以登上山顶俯瞰整个青岛老城区。山顶有一座红色的球形建筑，像巨大的红色气球，是一座旋转的观景台。可以俯瞰整个青岛老城区的红色屋顶和蓝色海面。青岛的德式建筑让人感觉一下子来到了欧洲，仿佛不在国内旅游。  

从山顶俯瞰城市给人一种平静，像是所有的喧嚣都被隔绝在了山下。就像坐飞机的时候，可以暂时从生活的忙碌中抽离，只是静静地看着窗外的风景，感受着自然的秩序和人类的伟大与渺小。  

![俯瞰青岛老城区](/assets/images/2026-08-09_jiaodong_travel_p1_img13.jpg){:width="75%" style="display: block; margin: 0 auto;"}

![海港与海面](/assets/images/2026-08-09_jiaodong_travel_p1_img14.jpg){:width="75%" style="display: block; margin: 0 auto;"}

在信号山公园上一看就是一个下午，像被钩住了魂一样舍不得离开。我们在山顶上带了很久，直到日落。日落后我们也没有离开，山顶的夜景也很美。夜晚的青岛老城区灯火通明，红色屋顶在灯光下显得格外温暖。远处的高楼大厦的灯光闪烁，窗户里面投出温柔的黄色。  

这次出游没带三脚架，这几张夜景是相机放在地上长曝光的结果。  

![夜晚的青岛](/assets/images/2026-08-09_jiaodong_travel_p1_img15.jpg){:width="75%" style="display: block; margin: 0 auto;"}
